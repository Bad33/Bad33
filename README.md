## Featured project

### [PolicyProof](https://github.com/Bad33/policyproof)

An evaluation-first RAG system that checks whether answers about AI governance are supported by reliable evidence and precise citations.

It includes reproducible document processing, retrieval evaluation, evidence-sufficiency assessment, provenance tracking, and abstention handling.
