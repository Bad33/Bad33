## 🔬 Research Impact

### Geographical Equity in Cancer-Trial Access

Processed **958 clinical trials** and geocoded trial locations across more than **4,400 US ZIP codes**.

The analysis found that rural hepatocellular-carcinoma populations had approximately **9.6% trial access**, compared with **71% for urban populations**, within the evaluated access criteria.

### AML Mortality Prediction

Developed mortality-prediction pipelines using clinical and genomic information from a **207-patient AML cohort**.

Compared logistic regression, gradient boosting, and XGBoost using nested stratified cross-validation, with strict nested-CV AUROC reaching approximately **0.81 for early-death prediction**.
