## 🚀 Current Focus: PolicyProof

**[PolicyProof](https://github.com/Bad33/policyproof)** is a research-driven RAG and citation-verification system for public AI-governance and regulatory documents.

The project is being developed from first principles with controlled corpus ingestion, source provenance, deterministic retrieval evaluation, abstention handling, offline model verification, and reproducible generated artifacts.
